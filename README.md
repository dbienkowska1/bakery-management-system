# Bakery Management System

Web application for managing an online bakery developed using PHP and MySQL.

## Features

* Customer registration and login
* Product catalog
* Shopping cart
* Order management
* Customer account panel
* Administrative dashboard
* Product management
* Ingredient management
* Allergen management

## Technologies

* PHP
* MySQL
* HTML
* CSS
* JavaScript

## Installation

1. Import `cukiernia.sql` into MySQL.
2. Copy the project folder into the web server directory.
3. Configure database connection settings.
4. Run the application locally.
